Take-home task · Physitrack MoCap

Rep Counter

A patient does squats in front of a camera. The browser turns the video into one number per frame: the knee angle, about 172° standing and about 90° in a deep squat. Build a small app that counts the squats and keeps a history of sessions.

Stack Node · TypeScript · React

Unfinished is fine; tell us what you'd do next. Download the fixture files below.

What counts as one rep

The angle goes below 100°, then comes back above 160°. Nothing else counts.

The data

Each file in fixtures/ is one session, sampled at 30 frames per second.

What to build

  1. countReps(angles) in TypeScript, with tests against the fixtures.
  2. Backend (Node + TypeScript, any framework, any storage):
    • POST /sessions saves a session result: { sessionId, reps, durationSec, performedAt }. Devices retry on bad connections, so the same sessionId can arrive twice. It must be saved once.
    • GET /sessions lists the caller's sessions.
    • Every request needs a token. A patient sees only their own sessions. A hard-coded token per user is fine.
  3. Frontend (React + TypeScript): pick a fixture file, count the reps in the browser, send the result, show the list of sessions. The angles stay in the browser; only the result goes to the server.
